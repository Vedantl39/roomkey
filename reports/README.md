# Roomkey weekly report

The first report will appear here on the Monday after analytics goes live.

It's written by the insights agent in [`agent/`](../agent) and committed by the
[Weekly report](../.github/workflows/weekly-report.yml) workflow. You can also
run it any time from the **Actions** tab: **Weekly report > Run workflow**.

Counts only: Roomkey never records note contents, PINs or keys, and reports
leave out room codes, room names and user IDs.
